# Spec: other-tabs

**Phase:** 1
**Route:** `/banmore/production` (Q / C / D / M / S category tabs)
**Status:** draft
**Blast radius:** YELLOW — five tab variants × four sections

## Prerequisites
- Spec 05 (Productivity tab landed across at least Mixing)
- Spec 11 (other sections landed) — preferable but not strict

## Purpose

Bring up the remaining Production category tabs per BRD §6.3 (`FR-P7`–
`FR-P9`) and the artifact's Production KPI matrix. Inventory (tab "I")
is spec 15.

## Scope

- **Quality (Q)** — first-pass KPI set per section. KPIs and drills are
  derived from mock data; the dedicated Quality Dashboard (§7,
  `FR-Q1`–`FR-Q6`) is a Phase 2 surface — Phase 1 just shows the Q
  tab inside Production.
- **Cost (C)** — KPIs per section (cost per MT, energy cost,
  utility consumption).
- **Delivery (D)** — KPIs per section (OTIF-like, schedule adherence).
- **Morale (M)** — KPIs per section (attendance, manpower).
- **Safety (S)** — KPIs per section (Days Without Reportable Incident
  counter, safety observations).

## Out of scope
- Inventory tab — spec 15.
- Quality Dashboard surface (§7) — Phase 2.
- Edit / manual KPI input (Q-USR-01: single role, read-only).
